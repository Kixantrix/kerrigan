# Foal Rescue Meadow 🐴🫧

A cozy bubble-pop idle game. Pop bubbles to rescue baby horses, watch them
grow up in your meadow, and come back later to find new foals born while you
were away.

- No ads, no timers, no lives — just bubbles and baby horses
- Saves automatically (localStorage), including progress while away
- Made for phone browsers; can be installed to the home screen

## Files

- `index.html` — the whole game (single self-contained file, installable web app build)
- `foal-rescue-meadow.html` — same game in artifact format (no document wrapper)
