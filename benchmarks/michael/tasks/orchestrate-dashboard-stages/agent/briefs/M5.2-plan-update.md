# M5.2: `kerrigan.plan-update` MCP tool (`src/plan-update.ts`) (excerpt)

## Goal
Apply a structured edit (replace a stage, add a stage, edit a stage's
dependencies) to a project's `plan.md`, commit it to a branch and open a draft
PR (AC-008, AC-011). `edit` is a discriminated union:
`{ op: "replace-stage", stageId, markdown }` |
`{ op: "add-stage", afterStageId?, markdown }` |
`{ op: "edit-deps", stageId, dependencies: string[] }`.
Apply the edit to the plan markdown, operating on the heading/section for
`stageId`.

## Constraints
- Structured errors on failure, no crash.
- Don't reimplement stage parsing from scratch if a shared helper exists — but
  this tool is server-side, so a self-contained markdown-section edit is fine;
  keep it robust (match the stage by its `## ` / `### ` heading text/slug).

`apps/kerrigan-dashboard/src/lib/plan-parser.ts` (heading/slug conventions).
