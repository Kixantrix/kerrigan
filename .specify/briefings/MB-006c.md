## Prior decisions

- User selected direct CLI + MXC on this laptop for the first pilot. Model
  inference remains cloud-hosted; the agent/tools now run locally.
- CLI sandbox settings are separate from app settings. `--sandbox` is documented
  as session-only; verify installed semantics rather than changing global defaults.
- MXC on macOS uses Seatbelt, not a VM/container. The CLI itself and built-in
  file tools are not OS-sandboxed; those tools require mechanical exclusion.
- Copilot CLI supports ordinary OAuth/browser login. Do not assume app login
  authenticates an isolated standalone CLI, and do not treat DNS failure as auth
  failure. Ask only if an actual supported sign-in flow is required.
- MB-005 and MB-006b provide read-only safety/evidence prior art. Linux subreaper
  and PID-fd logic does not establish macOS process cleanup.
- Official references:
  https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/about-cloud-and-local-sandboxes
  https://docs.github.com/en/copilot/how-tos/cloud-and-local-sandboxes/using-local-sandboxing
