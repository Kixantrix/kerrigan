- AC-MB-008a — level: integration — environment: cloud-linux — test: catalog schema/coverage tests (tbd `tests/projects/michael_bench/test_curriculum.py`).
  A curriculum catalog covering all eight spec families (Implement, Understand
  and plan, Research, Review and repair, Operate, Experiment, Design, Orchestrate).
  Each family has at least two candidate tasks, mined from the user's real
  merged history: commits, PRs, issues and session outcomes. Each candidate
  records source repo and exact base/reference refs, an objective outcome
  evidence type, a privacy class and an estimated agent time. Weight candidates
  toward the observed mix: Experiment and Operate must not be token entries.
  Include at least two long-horizon tasks expected to take more than 30 minutes.
- AC-MB-008b — level: integration — environment: cloud-linux (Docker) — test: per-package calibration tests.
  At least one fully calibrated package each for Experiment, Review and repair,
  Understand and plan, and Operate. Each package has:
  - an exact-base export with no hidden, reference or history leakage;
  - a public task statement;
  - an independent grader with no host execution of candidate code;
  - calibration showing the baseline fails and the reference passes.
  Use the existing replay_grader pattern, generalized minimally.
  Where judgment is irreducible (plans, research synthesis), the grader is an
  explicit required-facts/constraint checklist with deterministic checks first.
  Any residual rubric is recorded for later, not used as a model judge.
- AC-MB-008c — level: integration — environment: cloud-linux — test: existing grader suite.
  Finish independent graders and calibration for the remaining two historical
  coding replays (grouping, status), so Implement has three tasks.
- AC-MB-008d — level: unit — environment: cloud-linux — test: contract validation.
  Every new package validates against the existing task/result contracts and
  ledger, so it is runnable by the existing native trial path without new
  runner code beyond a per-task policy file.
