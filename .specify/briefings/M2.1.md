# M2.1: Tauri 2 + Vite + React + TS + Tailwind scaffold

Single-dispatch task from [`specs/projects/kerrigan-dashboard/tasks.md`](../../specs/projects/kerrigan-dashboard/tasks.md) Milestone 2.

## Goal

Scaffold the kerrigan-dashboard desktop app shell under `apps/kerrigan-dashboard/`. This is plumbing only — no business logic, no GitHub integration, no plan parsing. Subsequent tasks (M2.2 / M2.3 / M2.4 / M2.5) fill in capability.

## Hard constraints

- **No business logic.** Tauri commands stub only. No Octokit, no fs reads outside config dir, no plan parsing.
- **No scroll invariant.** The placeholder route must respect the same no-scroll rule M1 establishes (everything fits in viewport at 1280×800 and 1920×1080). Use the design tokens already in `specs/projects/kerrigan-dashboard/previs/index.html` — extract color palette, font stack, spacing scale into `tailwind.config.ts`.
- **Strict TS.** `tsconfig.json` with `"strict": true`, `"noUncheckedIndexedAccess": true`, `"exactOptionalPropertyTypes": true`.
- **AC-001 cold start budget.** App must open from `pnpm dev` and show first paint in <1s on a developer laptop. Don't import anything large in the initial route.

## What "done" looks like

1. `pnpm install` at repo root succeeds.
2. `pnpm -C apps/kerrigan-dashboard dev` opens a Tauri window showing a placeholder route with the app's color palette + typography (header bar saying "kerrigan" + version, empty content area styled per pre-vis tokens).
3. `pnpm -C apps/kerrigan-dashboard tauri build` produces an installer artifact (any platform you can run in CI; the cross-platform matrix is M2.5's job).
4. `pnpm -C apps/kerrigan-dashboard lint` passes.
5. `pnpm -C apps/kerrigan-dashboard test` runs one Vitest sanity test and passes (e.g. `expect(1+1).toBe(2)` is fine — point is the harness works).
6. `tsc --noEmit` clean under strict.
7. Placeholder route asserts no-scroll via a Playwright test at 1280×800 (add `tests/projects/kerrigan_dashboard/test_shell_no_scroll.py` — Python+Playwright is consistent with existing M1 tests).
8. `kerrigan check` passes (no new validator failures).
