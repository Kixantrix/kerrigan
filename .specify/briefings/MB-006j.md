## Objective

Build an offline, independently authoritative grader for the already calibrated
Python validator replay, ready for later native/local-model adapters. Do not
run another model or expand the canary allowance.

- AC-MB-002/003: Consume the exact existing validator package/source boundaries,
  preserve all 15 preservation and 10 held-out assertion semantics, including
  legacy parser compatibility. Maintain an auditable mapping to original test
  IDs. Recalibrate exact base (15/15 preservation, 7/10 regression) and reference
  (25/25 total) under the new isolated grader, reporting every denominator.
  Any discrepancy is a blocker, not permission to weaken/omit tests.
  Level: integration; environment: cloud-linux; test: new focused grader tests.
- AC-MB-003/004: Candidate source executes only in a fresh bounded offline
  Docker process, never on the host or in the trusted verdict authority.
  Candidate receives behavioral probe inputs and an answer-free harness, never
  expected answers, assertion code, reference source, repository/history, host
  credentials/socket mounts or a writable trusted-verdict location. Trusted
  comparisons operate on bounded validated observations after owned candidate
  exit. Existing pytest importing candidate in the verifier process is NOT
  independent grading. Reuse existing bounded Docker/probe patterns where
  suitable without importing dependencies unrelated to this slice.
  Level: integration; environment: cloud-linux; test: malicious candidate probes.
- AC-MB-004: Bound candidate source, all input/output/framing, probe count,
  processes/memory/time and cleanup. Candidate exit/stdout/sentinel/fabricated

  OOM and evaluator failure remain explicit, with no manufactured completion.
  Recovery never replays candidate actions or signals guessed PIDs.
  Level: integration; environment: cloud-linux; test: spoof/tamper/overflow/
  timeout and owned-cleanup cases, not just normal reference calibration.
- AC-MB-003/005: Return source/package/verifier-policy hashes, per-assertion
  preservation/regression diagnostics and independently established verdict.
  Separate staging/candidate execution/verification/cleanup timings on a
  same-host monotonic clock. No model time or end-to-end task completion is
  implied without an actual model trial.
  Level: integration; environment: cloud-linux; test: report-shape/error cases.
- AC-MB-008: Provide one small reproducible offline reference-grade smoke path,
  with dependencies/image preprovisioned, executed twice with fresh owned
  state; no credentials/inference. Document exact setup/invocation/results.
  Level: smoke; environment: cloud-linux; test:
  benchmarks/michael/replay_grader/scripts/smoke.sh.
