# Briefing: MB-009r live multi-family trials (MAI vs Sonnet)

## Objective
Run both selected models on all 7 calibrated curriculum packages through the
real native path, grade each run independently, run the automated admission
and quality machinery, and publish a per-family comparison. Operate under the
standing autonomy rule in plan.md: never ask the human; fix and rerun harness
failures; model failures are results.

## Acceptance criteria
- AC-r1 — level: integration — environment: local-attested-macos — test: tests/projects/michael_bench/test_replay_trial.py (extend).
  Generalize the MB-006l native trial path from validator-only to any
  curriculum package via its `native-policy.json`. Add a pinned Node 24
  runtime, read-only and no-fork, for TypeScript packages. Keep the policy
  and safety properties of MB-006l: post-quiescence collection, independent
  Docker grading, and exact-byte binding. Rerun real native offline fixtures
  (oracle injection) per package. Every package must reproduce its calibrated
  base and reference counts through the native path before any live run.
- AC-r2 — level: integration — environment: local-attested-macos — test: admission report.
  Run admission for all 7 packages:
  - the LLM artifact audit (instruction vs tests vs oracle);
  - a blind re-implementation by a model family other than the two under test.
  Use `benchmarks/michael/curriculum/admit`. Promote each package to admitted,
  or fix or retire it with a recorded reason. Audit verdicts never score models.
- AC-r3 — level: scenario — environment: local-attested-macos — test: live outcomes archive.
  For each admitted package, run one attempt each for `mai-code-2` then
  `claude-sonnet-5.5`, with a frozen self-sealed condition per package.
  Before each prompt, prove fresh HTTPS and an effective sandbox. Record
  time to verified completion, tokens and partial counts. Run LLM failure
  attribution on every non-pass. On task- or harness-caused failures, fix,
  re-freeze and rerun as a new disclosed attempt.
- AC-r4 — level: integration — environment: local-attested-macos — test: report.
  Compute deterministic quality signals and the cross-family blind quality
  panel, separately from pass/fail. Report the panel's calibration agreement.
  Publish `benchmarks/michael/curriculum/results-v1.md` with a per-family table
  (pass, partial counts, time, tokens, quality) and honest limits (n=1 per
  model and task, public exposure).
- AC-r5 (stretch) — run the 10 public anchors for both models if time permits;
  otherwise record exactly what blocks them.

## Scope
Touch: `benchmarks/michael/{local_transport,replay_trial,curriculum,replay_grader}/**`
and their tests. Read-only: task package sources, prior evidence and slots.
No PR. No credential inspection. No host execution of candidate code.

## Budget
max_turns: 120. Report back with results and a concise comparison.
