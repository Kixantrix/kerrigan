# Briefing: MB-010r live trials on curriculum v2

## Objective
Admit and run MAI then Sonnet on all MB-010c packages, then publish
results-v2. This is the first round designed to discriminate, with
long-horizon tasks, multi-file changes and the previously empty families.
Standing autonomy applies.

## Acceptance criteria
- AC-r1 — level: integration — environment: local-attested-macos — test: test_replay_trial.py / test_curriculum_native.py.
  Multi-file native collection. After quiescence, `collect` reads every path
  in `policy["artifacts"]` using the same no-follow, exact-byte binding as
  today. It passes `specs.bundle(files)` to `grader.grade`. Add
  `replay_grader/harnesses/*.mjs` to the hashed sources. Single-file packages
  and all prior evidence stay unchanged. Reproduce every v2 package's
  base/reference counts through the native path before inference.
- AC-r2 — level: integration — environment: local-attested-macos — test: admission.json.
  Run the frozen two-family LLM audit and the Gemini blind re-implementation
  for all 13 provisional packages; the 5 v1 packages keep their decisions.
  Admit, fix or retire each with a recorded reason. Fixes are new versions.
- AC-r3 — level: scenario — environment: local-attested-macos — test: live archive.
  On every newly admitted package, run one attempt each for MAI then Sonnet,
  with a self-sealed frozen condition. Raise the active limit as long-horizon
  tasks need, with a finite ceiling of at most 3 hours, declared per package.
  Before each prompt, prove fresh HTTPS and an effective sandbox. Attribute
  every non-pass. Fix and rerun task- or harness-caused failures as new
  disclosed attempts; model failures are results.
- AC-r4 — level: integration — environment: local-attested-macos — test: report.
  Publish `benchmarks/michael/curriculum/results-v2.md`:
  - a per-family table with pass rate, partial counts, time to verified
    completion, tokens and quality-panel results;
  - a METR-style success-versus-estimated-human-time summary;
  - a pooled v1+v2 view, keeping each round's conditions labeled;
  - honest limits, including n=1.
