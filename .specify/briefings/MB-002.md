## Prior decisions and research

- Existing-engine-first: Inspect AI and Harbor are candidates, not both mandatory dependencies. Inspect is the first candidate to assess for broad composition; select only after offline evidence. Inspect's in-process agent bridge grants host access and is not acceptable for executing generated code. Use an actual sandbox boundary.
- Current official references: https://inspect.aisi.org.uk/agent-bridge.html and https://docs.harborframework.com/tasks/overview (checked November 24, 2026). Harbor packages require tests/solutions remain outside the agent view until verification; packaging alone is not isolation proof.
- Read current upstream docs/version before implementation. Use one engine and the smallest useful compatibility fixture, not multiple integrations or a custom orchestration rewrite. If it cannot satisfy a criterion, report the concrete gap; do not downgrade isolation or fabricate a pass.
- Existing pure contracts are integrated at c2c73df. Unknown identity/timing/credits stay unknown. Fake events are synthetic; this proof is not a scored MAI Code 2/Sonnet evaluation.
- Scored cloud Copilot sessions later need independently enforced isolation and timeouts. A Docker/offline engine proof alone does not establish the app can enforce those controls.
