## Prior decisions

- This session is a trusted preflight, not an evaluated task agent. The benchmark repository already contains gold and hidden tests; merely starting an app cloud session on it cannot prove answer isolation.
- MAI Code 2 (`mai-code-2`) and Claude Sonnet 5.5 (`claude-sonnet-5.5`) are the selected practical-system candidates. Do not substitute another model silently or infer isolated-model causality from native harness comparisons.
- The offline Docker CLI proof is separate. Native tool routing, session termination, requested/observed identity, and answer-free delivery remain unproven.
- First pilot: three tasks per model, one fresh session/attempt per pairing, sequential, 60 active minutes plus bounded cleanup, no retries. No trial starts until identity/isolation/deadline gates are satisfied.
- Public CLI docs describe model pinning and tool allowlists, but their existence does not prove this app's cloud-session launch path exposes them. Inspect actual help/current host behavior.
- Do not read tokens, environment dumps, credential files, or private unrelated paths. Harmless canaries must use synthetic contents and owned locations only. Do not exploit or bypass any runtime restriction.
