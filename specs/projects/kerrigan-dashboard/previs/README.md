# kerrigan-dashboard · Pre-vis (M1)

This is the design-lock pre-visualization for the kerrigan-dashboard project — a single self-contained `index.html` file (HTML + CSS + JS, no build tooling, no framework) that demonstrates the portfolio card grid, the project-detail three-pane layout (plan editor · DAG canvas · chat), and three variants of the PR-flow show-stopper animation (dots, line trail, glow trail). Open `index.html` directly in any Chromium-based browser; no server required.

See [`../spec.md`](../spec.md) for the full product spec and acceptance criteria, and [`../design-references.md`](../design-references.md) for the locked visual decisions this mockup implements.
